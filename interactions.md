Dashboard Card Interactions:
1-Assets by currency:
- click currency group -> go to assets view filtered by that currency
2-Breakdown by Institution:
- click breakdown group -> go to accounts view filtered by that institution
3-Budget Progress:
- click budget progress -> go to budget details view
4-Cash Flow:
- click income/expense cash flow bar -> go to transactions view filtered by that cash flow type and the selected period 
5-Cash Flow Sankey:
- click on any flow in the Sankey diagram -> go to transactions view filtered by that flow type and the selected period
- clicking summary Income/Expense -> go to transactions view filtered by type and the selected period
6-Daily Cash Flow:
- click on any daily cash flow bar -> go to transactions view filtered by that day
7-Transactions:
- click on any transaction -> go to transaction details view
8-Asset Allocation:
- click on any asset allocation segment -> go to assets view filtered by that asset type
9-Estimated Interest:
- click on card -> go to account/liability details view

Real Estate View Card:
- Real Estate Image

Transactions View Card:
- click on account name -> filter transactions by that account
- click on category name -> filter transactions by that category

Transaction Details View Card:
- click on account name (link style) -> go to account details view
